"축지법"(이하 "운영자")은 「개인정보 보호법」 등 관련 법령을 준수하며, 다음과 같이 개인정보 처리방침을 수립·공개합니다.

## 제1조 (수집하는 개인정보 항목 및 수집방법)

| 구분                                | 수집 항목                                                                                   | 수집 방법                                                                                |
| ----------------------------------- | ------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 관리자 회원가입                     | 이름, 이메일, 부서, 직급                                                                    | 가입 화면에서 이용자가 직접 입력 (공무원은 공무원 메일, 외부 업체 등은 일반 메일로 가입) |
| 사용자 회원가입(카카오 소셜 로그인) | 카카오 계정 식별값(회원번호), 닉네임, 이메일(카카오 동의 시), 프로필 이미지(카카오 동의 시) | 카카오 로그인 연동 시 이용자 동의 하에 카카오로부터 제공받음                             |
| 사용자 회원가입(일반 로그인)        | 사용자 이름, 전화번호, 생년월일                                                             | 가입 화면에서 이용자가 직접 입력                                                         |
| 리뷰 등록                           | 작성한 리뷰 내용                                                                            | 리뷰 작성 화면에서 이용자가 직접 입력                                                    |
| 서비스 이용                         | 서비스 이용 기록, 접속 로그                                                                 | 서비스 이용 과정에서 자동 생성                                                           |
| 계정 설정                           | 프로필 정보 등                                                                              | 계정설정 화면 입력                                                                       |

## 제2조 (개인정보의 수집 및 이용 목적)

1. 회원 식별 및 서비스 제공
2. 관리자 회원의 소속 확인 및 관리자 서비스 제공
3. 사용자 서비스 제공
4. 서비스 개선, 통계 분석, 부정이용 방지

## 제3조 (개인정보의 보유 및 이용기간)

1. 회원 탈퇴 시 지체 없이 파기하는 것을 원칙으로 합니다. 다만 관계 법령에 따라 보존이 필요한 경우 해당 기간 동안 보관합니다.
   - 통신비밀보호법에 따른 접속 로그 기록: 3개월
2. 회원이 작성한 리뷰는 회원 탈퇴 시 삭제하거나 개인을 알아볼 수 없도록 비식별 처리합니다.
3. 서비스 이용 기록은 비식별 처리 후 통계 목적으로 활용될 수 있습니다.

## 제4조 (개인정보의 제3자 제공)

운영자는 원칙적으로 회원의 개인정보를 외부에 제공하지 않습니다. 다만 다음의 경우는 예외로 합니다.

- 회원이 사전에 동의한 경우
- 법령의 규정에 의거하거나 수사기관의 요청이 있는 경우

## 제5조 (개인정보 처리의 위탁)

운영자는 현재 개인정보 처리 업무를 외부에 위탁하지 않습니다. 위탁이 필요한 경우 수탁자와 위탁 업무의 내용을 이 방침에 공개하고, 법령에 따라 필요한 절차를 거치겠습니다.

회원은 언제든지 다음의 권리를 행사할 수 있습니다.

1. 개인정보 열람, 정정, 삭제 요구
2. 회원 탈퇴(처리정지) 요구
3. 작성한 리뷰 등 저장된 데이터 삭제 요청
   권리 행사는 [chookjibup@gmail.com](mailto:chookjibup@gmail.com)을 통해 가능합니다.

운영자는 개인정보 보호를 위해 다음과 같은 조치를 취합니다.

- 카카오 소셜 로그인 인증 토큰의 안전한 관리 및 세션 만료 처리

- 접속 로그 보관 및 위변조 방지
